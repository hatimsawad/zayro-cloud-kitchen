# ZAYRO Cloud Kitchen

Responsive bilingual (French / Arabic) landing page for the ZAYRO Cloud Kitchen project.

## Preview locally
Open `index.html` in a browser. No build step or package installation is required.

## Deploy on Render
This repository includes `render.yaml` for a Render Static Site. Connect the GitHub repository to Render and deploy the Blueprint.

## Before accepting real orders
- Confirm the final menu and prices.
- Add the business WhatsApp/order phone number and connect the checkout flow.
- Confirm delivery zones, opening hours, and contact details.
- Replace the sample food photography with approved brand photography.

The cart is currently a visual/demo cart and does not submit orders or charge customers.
